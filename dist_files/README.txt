制度汇编管理系统 v1.1.0
========================


一、系统简介
-----------
本系统用于集中管理各类监管制度文件，支持分类管理、全文搜索、
批量导入、回收站等功能。

主要特性：
  - 制度文件的增删改查，支持 .doc / .docx / .pdf 格式
  - 按分类目录组织制度文件，支持自定义分类
  - 全文搜索：不仅搜索标题和文号，还能搜索文档正文内容
  - 搜索高亮：关键词黄色背景高亮，显示正文摘要片段
  - 文号自动识别：从文件名中自动提取文号
  - 批量导入：一次导入整个文件夹的制度文件
  - 回收站：误删的制度可从回收站恢复
  - 数据备份/恢复：一键备份为 ZIP 文件
  - 界面设置：字体大小可调节，支持实时预览


二、运行环境
-----------
  - 操作系统：Windows 7 SP1 / 8 / 10 / 11（32位和64位均可）
  - 分辨率：建议 1280x720 以上
  - 无需安装 Python 或其他依赖，解压即用
  - 如提示缺少 VCRUNTIME140.dll，请安装 VC++ 2015-2022 运行库
    下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe


三、快速开始
-----------
  1. 双击 RegulationManager.exe 启动程序
  2. 程序界面分为三部分：
     - 左侧：分类目录导航栏
     - 中间：制度文件列表
     - 右侧：工具栏（搜索、排序、新增等）
  3. 点击工具栏 "+ 新增制度" 添加单个文件
  4. 点击 "批量导入" 一次导入整个文件夹


四、功能说明
-----------

【4.1 添加制度】
  方式一：单个添加
    1. 点击工具栏 "+ 新增制度" 或按 Ctrl+N
    2. 选择制度文件（.doc/.docx/.pdf）
    3. 系统自动从文件名提取文号（如"银监发〔2014〕40号"）
    4. 填写标题、选择分类、状态等信息
    5. 点击"保存"

  方式二：批量导入
    1. 点击工具栏 "批量导入"
    2. 选择包含制度文件的文件夹
    3. 选择目标分类
    4. 系统自动导入所有支持格式的文件
    5. 文件名中含"已废止"/"废止"/"失效"的，自动标记为废止状态

【4.2 编辑制度】
  1. 在制度列表中，点击某行右侧的 "编辑" 按钮
  2. 可修改：标题、文号、分类、状态、发文机关等信息
  3. 修改后点击"保存"，列表自动刷新

【4.3 搜索】
  1. 在顶部搜索框输入关键词
  2. 支持搜索：标题、文号、部门、发文机关、文档正文内容
  3. 按回车或点击"搜索"按钮
  4. 搜索结果中关键词会以黄色背景高亮显示
  5. 每条结果下方会显示包含关键词的正文摘要
  6. 双击标题可直接打开对应的源文件
  7. 点击"清空"按钮清除搜索条件

【4.4 分类管理】
  添加分类：点击左侧底部 "+ 添加分类"
  删除分类：右键点击分类名称 → 删除（该分类下的制度不会被删除）

【4.5 删除与恢复】
  删除制度：选中制度后点击 "删除"，制度移入回收站
  批量删除：勾选多个制度后点击 "批量删除"
  恢复制度：左侧点击"回收站" → 勾选要恢复的制度 → 点击"还原"
  彻底删除：在回收站中选择"彻底删除"（此操作不可恢复）

【4.6 备份与恢复】
  备份：菜单 → 文件 → 备份制度库（生成 ZIP 文件） 
  恢复：菜单 → 文件 → 恢复制度库 → 选择 ZIP 备份文件

【4.7 统计看板】
  左侧点击"统计看板"，可查看：
  - 制度总数
  - 分类数量
  - 各状态分布（现行有效/已废止等）

【4.8 系统设置】
  菜单 → 工具 → 系统设置
  - 字体大小调节：10px ~ 18px，滑动滑块实时预览
  - 快捷预设：小(12)、中(14)、大(16)
  - 设置自动保存，下次启动自动应用


五、支持的文件格式
-----------------
  格式        说明                  全文搜索
  .doc        Word 97-2003          支持（自动提取正文）
  .docx       Word 2007+            支持（自动提取正文）
  .pdf        PDF 文档              支持（自动提取正文）


六、状态说明
-----------
  现行有效：制度当前有效，正在执行
  已归档：  制度已归档保存
  已被替代：制度已被新版本替代
  已废止：  制度已废止失效

  提示：文件名中含"已废止"/"废止"/"失效"的文件，
  导入时会自动标记为"已废止"状态。也可手动在编辑中修改。


七、快捷键
-----------
  Ctrl+N    新增制度
  Ctrl+Q    退出程序


八、数据存储
-----------
所有数据保存在程序同级的 data 文件夹中：

  data/regulation.db     数据库（制度信息、分类、全文索引）
  data/documents/        导入的制度文件
  data/backups/          手动备份文件
  data/logs/             运行日志

重要提示：
  1. 请定期备份 data 文件夹！
  2. 不要删除 regulation.db，否则所有制度记录将丢失
  3. 不要删除 documents 文件夹，否则制度文件将无法打开
  4. 迁移到新电脑时，复制整个程序文件夹（含 data 目录）即可


九、常见问题
-----------
Q: 双击 exe 无法启动？
A: 确保路径中不含特殊字符，尝试以管理员身份运行。

Q: 搜索不到正文内容？
A: 首次启动时系统会自动提取已有文档的正文。新导入的文件会自动提取。
   如仍有问题，点击菜单"工具 → 重建搜索索引"。

Q: 数据库损坏？
A: 用 data/backups/ 中的备份文件替换 data/regulation.db 即可恢复。
   如无备份，可删除 regulation.db 后重启程序（数据将丢失）。

Q: 如何迁移到新电脑？
A: 复制整个程序文件夹（包含 data 目录）到新电脑即可。

Q: 导入的文件在别的电脑上打不开？
A: 确保 data/documents/ 文件夹和 exe 在同一目录下。
   程序使用相对路径存储，分发时请确保 data 文件夹完整。
