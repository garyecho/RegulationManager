制度汇编管理系统 v1.2.3
========================


一、系统简介
-----------
本系统用于集中管理各类监管制度文件，支持分类管理、全文搜索、
批量导入、回收站等功能。

主要特性：
  - 制度文件的增删改查，支持 .doc / .docx / .pdf 格式
  - 按分类目录组织制度文件，支持自定义分类
  - 全文搜索：不仅搜索标题和文号，还能搜索文档正文内容
  - 搜索高亮：关键词黄色背景高亮，显示正文摘要片段
  - 文号自动识别：从文件名中自动提取文号
  - 批量导入：一次导入整个文件夹的制度文件
  - 重复检测：新增和批量导入时自动检测重复文件，弹出提示
  - 回收站：误删的制度可从回收站恢复
  - 数据备份/恢复：一键备份为 ZIP 文件
  - 界面设置：字体大小可调节，支持实时预览
  - 列自定义：拖拽列头调整顺序，拖拽边框调整列宽，自动保存


二、运行环境
-----------
  - 操作系统：Windows 7 SP1 / 8 / 10 / 11（32位和64位均可）
             银河麒麟 v10 SP1 / v11（x86_64 架构）
  - 分辨率：建议 1280x720 以上
  - 无需安装 Python 或其他依赖，解压即用
  - Windows 如提示缺少 VCRUNTIME140.dll，请安装 VC++ 2015-2022 运行库
    下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe


三、快速开始
-----------

【Windows 系统】
  1. 解压程序压缩包到任意目录
  2. 双击 RegulationManager.exe 启动程序
  3. 程序界面分为三部分：
     - 左侧：分类目录导航栏
     - 中间：制度文件列表
     - 右侧：工具栏（搜索、排序、新增等）

【银河麒麟系统】
  方式一：双击直接打开（不安装，推荐先试用）
    1. 解压程序压缩包到任意目录，不要只解压其中一个文件
    2. 双击「Launch_RegulationManager.desktop」
    3. 如果系统提示“是否允许启动”或“信任并启动”，请选择“允许启动”
    4. 程序窗口出现即表示成功。下次仍可双击这个文件打开

  方式二：双击安装到开始菜单（推荐长期使用）
    1. 双击「Install_RegulationManager.desktop」
    2. 出现系统密码窗口后，输入当前登录账户的密码，点击“认证”或“确定”
    3. 看到“安装完成”提示后，打开开始菜单
    4. 搜索并点击「制度汇编管理系统」即可打开
    5. 安装器会自动配置数据目录权限，普通用户无需手动执行 chmod/chown

  提示：如果双击 .desktop 文件打开的是文本编辑器，请看第十章的“终端兜底方法”。

【两个启动图标有什么区别？数据会不会丢失？】
  Launch_RegulationManager.desktop：
    - 直接运行当前解压文件夹中的程序，适合先试用
    - 数据保存在“当前解压文件夹/data/”中
    - 不需要密码

  Install_RegulationManager.desktop：
    - 将程序安装到开始菜单，适合长期使用
    - 首次安装需要输入系统密码，以后从开始菜单打开无需密码
    - 数据保存在“/opt/RegulationManager/data/”中

  重要提醒：上面两处 data 文件夹是两套独立数据，不会自动同步。
  安装时，当前解压文件夹中的数据会复制到安装目录。安装完成后，请统一从开始菜单打开程序。
  如果之后又双击原解压文件夹中的启动图标，看到的是原来的旧数据，并不是数据丢失。

  4. 点击工具栏 "+ 新增制度" 添加单个文件
  5. 点击 "批量导入" 一次导入整个文件夹


四、功能说明
-----------

【4.1 添加制度】
  方式一：单个添加
    1. 点击工具栏 "+ 新增制度" 或按 Ctrl+N
    2. 选择制度文件（.doc/.docx/.pdf）
    3. 系统自动从文件名提取文号（如"银监发〔2014〕40号"）
    4. 填写标题、选择分类、状态等信息
    5. 点击"保存"
    6. 如系统中已存在同名文件，会弹出重复提示，可选择继续导入或取消

  方式二：批量导入
    1. 点击工具栏 "批量导入"
    2. 选择包含制度文件的文件夹
    3. 选择目标分类
    4. 系统自动导入所有支持格式的文件
    5. 文件名中含"已废止"/"废止"/"失效"的，自动标记为废止状态

【4.2 编辑制度】
  1. 在制度列表中，点击某行右侧的 "编辑" 按钮
  2. 可修改：标题、文号、分类、状态、发文机关等信息
  3. 修改后点击"保存"，列表和全文搜索索引自动同步刷新

【4.3 搜索】
  1. 在顶部搜索框输入关键词
  2. 支持搜索：标题、文号、部门、发文机关、文档正文内容
  3. 按回车或点击"搜索"按钮
  4. 搜索结果中关键词会以黄色背景高亮显示
  5. 每条结果下方会显示包含关键词的正文摘要
  6. 双击标题可直接打开对应的源文件
  7. 点击"清空"按钮清除搜索条件

【4.4 分类管理】
  添加分类：点击左侧底部 "+ 添加分类"
  删除分类：右键点击分类名称 → 删除（该分类下的制度不会被删除）

【4.5 删除与恢复】
  删除制度：选中制度后点击 "删除"，制度移入回收站
  批量删除：勾选多个制度后点击 "批量删除"
  恢复制度：左侧点击"回收站" → 勾选要恢复的制度 → 点击"还原"
  彻底删除：在回收站中选择"彻底删除"（此操作不可恢复）
  提示：彻底删除会同步清理标签和搜索索引；重复记录共用的文件仅在最后一条记录删除时清理

【4.6 备份与恢复】
  备份：菜单 → 文件 → 备份制度库（生成 ZIP 文件） 
  恢复：菜单 → 文件 → 恢复制度库 → 选择 ZIP 备份文件

【4.7 统计看板】
  左侧点击"统计看板"，可查看：
  - 制度总数
  - 分类数量
  - 各状态分布（现行有效/已废止等）

【4.8 系统设置】
  菜单 → 工具 → 系统设置
  - 字体大小调节：10px ~ 18px，滑动滑块实时预览
  - 快捷预设：小(12)、中(14)、大(16)
  - 设置自动保存，下次启动自动应用

【4.9 表格列自定义】
  - 拖拽列头：可以拖拽列头来调整列的显示顺序
  - 调整列宽：拖拽列之间的边框来调整列宽
  - 自动保存：列的顺序和宽度会自动保存，下次启动自动恢复

六、状态说明
-----------
  现行有效：制度当前有效，正在执行
  已归档：  制度已归档保存
  已被替代：制度已被新版本替代
  已废止：  制度已废止失效

  提示：文件名中含"已废止"/"废止"/"失效"的文件，
  导入时会自动标记为"已废止"状态。也可手动在编辑中修改。

八、数据存储
-----------
所有数据保存在程序同级的 data 文件夹中：

  data/regulation.db     数据库（制度信息、分类、全文索引）
  data/documents/        导入的制度文件
  data/backups/          手动备份文件
  data/logs/             运行日志

使用 install.sh 安装到开始菜单后，数据位于：
  /opt/RegulationManager/data/
安装器会自动将该目录配置为当前使用者可读写。

重要提示：
  1. 请定期备份 data 文件夹！
  2. 不要删除 regulation.db，否则所有制度记录将丢失
  3. 不要删除 documents 文件夹，否则制度文件将无法打开
  4. 迁移到新电脑时，复制整个程序文件夹（含 data 目录）即可


九、常见问题
-----------
Q: 双击 exe 无法启动？
A: 确保路径中不含特殊字符，尝试以管理员身份运行。

Q: 搜索不到正文内容？
A: 首次启动时系统会自动提取已有文档的正文。新导入的文件会自动提取。
   如仍有问题，点击菜单"工具 → 重建搜索索引"。

Q: 数据库损坏？
A: 用 data/backups/ 中的备份文件替换 data/regulation.db 即可恢复。
   如无备份，可删除 regulation.db 后重启程序（数据将丢失）。

Q: 如何迁移到新电脑？
A: 复制整个程序文件夹（包含 data 目录）到新电脑即可。

Q: 导入的文件在别的电脑上打不开？
A: 确保 data/documents/ 文件夹和 exe 在同一目录下。
   程序使用相对路径存储，分发时请确保 data 文件夹完整。

Q: 麒麟系统双击启动图标后打开了文本编辑器？
A: 请右键点击 Launch_RegulationManager.desktop，选择“允许启动”或“属性 → 权限 → 允许作为程序执行”。
   如果系统没有此选项，请按下面“终端兜底方法”启动。

Q: 麒麟系统中文输入法无法使用？
A: 确保系统已安装 fcitx 输入法框架。如仍无法使用，在终端执行：
   sudo apt install fcitx-frontend-qt5 -y

Q: 安装时为什么会弹出密码窗口？
A: 安装到开始菜单需要系统授权。这是银河麒麟的正常安全保护，请输入当前登录账户密码。


十、终端兜底方法（双击无效时使用）
--------------------------------------
不要着急，按下面步骤操作即可。只需要复制或输入一行命令。

【如何打开当前文件夹的终端】
  1. 先打开本程序所在的文件夹。
  2. 在文件夹空白处点击鼠标右键。
  3. 选择“在终端中打开”或“打开终端”。
  4. 看到黑色或深色窗口，且光标在闪烁，即表示终端已打开。

【临时启动程序】
  在终端中输入下面这一行，然后按键盘 Enter：

    chmod +x start.sh && ./start.sh

  程序窗口出现，即表示启动成功。此操作不需要输入密码。

【安装到开始菜单】
  在终端中输入下面这一行，然后按键盘 Enter：

    ./install.sh

  随后通常会弹出图形密码窗口。输入当前登录账户密码后，点击“认证”或“确定”。
  如果没有出现密码窗口，终端会提示输入密码：

  1. 直接输入密码后按 Enter。
  2. 输入时屏幕不会显示任何字符，也不会显示星号，这是 Linux 的正常安全设计。
  3. 即使看起来没有输入内容，密码实际上已经输入；输入完直接按 Enter 即可。
  4. 看到“安装完成”或开始菜单出现「制度汇编管理系统」，即表示安装成功。

  如果提示“没有执行权限”，先输入下面这一行，再重新执行上面的命令：

    chmod +x install.sh start.sh
