制度汇编管理系统 v1.0.0
========================

一、系统简介
-----------
本系统用于集中管理各类监管制度文件，支持分类管理、全文搜索、
标签管理、批量导入导出、回收站等功能。


二、运行环境
-----------
- 操作系统：Windows 10 / 11
- 分辨率：建议 1280x720 以上
- 无需安装 Python 或其他依赖，解压即用


三、使用方法
-----------
1. 双击 RegulationManager.exe 启动程序
2. 首次启动会自动创建 data 文件夹和数据库
3. 点击工具栏 "+ 新增制度" 添加文件
4. 点击 "批量导入" 可一次导入整个文件夹的制度文件
5. 左侧分类目录支持右键删除分类
6. 底部 "+ 添加分类" 可新增自定义分类


四、支持的文件格式
-----------------
- .doc  （Word 97-2003）
- .docx （Word 2007+）
- .pdf  （PDF 文档）


五、快捷键
-----------
- Ctrl+N    新增制度
- Ctrl+Q    退出程序


六、数据存储
-----------
所有数据保存在 data 文件夹中：
- data/regulation.db     数据库（制度信息、分类、标签）
- data/documents/        上传的制度文件
- data/backups/          系统备份
- data/logs/             运行日志

重要：请定期备份 data 文件夹！详见 backup.txt


七、常见问题
-----------
Q: 双击 exe 无法启动？
A: 请确保路径中不含特殊字符，尝试以管理员身份运行。

Q: 中文显示乱码？
A: 系统会自动检测字体，如仍有问题请安装微软雅黑字体。

Q: 搜索不到内容？
A: 首次导入文件后需要等待索引建立完成，大文件可能需要几秒。

Q: 数据库损坏？
A: 用备份文件替换 data/regulation.db 即可恢复。

Q: 如何迁移到新电脑？
A: 复制整个程序文件夹（包含 data 目录）到新位置即可。
