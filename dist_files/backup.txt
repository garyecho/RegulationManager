制度汇编管理系统 — 数据备份说明
=================================

本系统所有数据（制度文件、数据库、标签、分类）均存储在
程序目录下的「data」文件夹中。


一、日常备份（推荐每周一次）
---------------------------
1. 关闭制度汇编管理系统
2. 复制整个「data」文件夹到安全位置（U盘、网盘、服务器等）
3. 建议用日期命名，例如：
   data_backup_20260605/


二、系统内置备份
---------------
程序内「文件 → 备份制度库」可一键创建备份，
备份文件保存在 data/backups/ 目录下。


三、恢复数据
------------
方法一（推荐）：用备份的 data 文件夹替换当前 data 文件夹
方法二：程序内「文件 → 恢复制度库」选择备份的 .zip 文件


四、重要提醒
-----------
★ data 文件夹包含您的所有制度文件和数据库，请妥善保管
★ 不要删除 data/regulation.db 文件，否则所有记录将丢失
★ 不要删除 data/documents/ 文件夹，否则制度文件将无法打开
★ 建议至少保留最近 3 个备份版本
★ 如需迁移到新电脑，只需复制整个程序文件夹即可


五、备份验证
------------
建议每季度做一次恢复测试：
1. 将备份的 data 文件夹复制到临时位置
2. 用它替换程序的 data 文件夹
3. 启动程序确认数据完整
4. 恢复原 data 文件夹
