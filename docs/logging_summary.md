# 日志系统改进总结

## 概述

为制度汇编管理系统添加了完善的日志记录功能，帮助开发者和管理员：
- 追踪用户操作流程
- 诊断系统问题和错误
- 监控系统性能
- 审计关键操作

## 新增文件

### 1. `utils/log_manager.py` - 日志管理器
- **功能**：增强的日志系统核心模块
- **特性**：
  - 日志轮转：按文件大小自动分割（默认10MB）
  - 日志备份：保留最近10个日志文件
  - 日志过滤：按级别、关键词、时间过滤
  - 日志统计：文件数量、大小、错误统计
  - 日志清理：一键清理旧日志文件
  - 日志导出：导出日志内容用于问题排查

### 2. `ui/log_dialog.py` - 日志查看对话框
- **功能**：图形化日志查看器
- **特性**：
  - 日志文件选择：下拉框选择不同日期的日志
  - 级别过滤：DEBUG/INFO/WARNING/ERROR/CRITICAL
  - 关键词搜索：支持文本搜索
  - 日志高亮：不同级别用不同颜色显示
  - 后台加载：使用线程避免界面卡顿
  - 导出功能：导出日志到文件
  - 清理功能：清理旧日志文件

### 3. `docs/logging_guide.md` - 日志使用指南
- **内容**：
  - 日志文件位置和格式说明
  - 日志级别详细解释
  - 三种日志查看方法
  - 常见问题排查指南
  - 日志管理建议
  - 开发者指南

## 使用方法

### 查看日志
1. 启动应用程序
2. 菜单栏 → **工具** → **查看系统日志**（快捷键：Ctrl+L）
3. 在日志查看器中浏览和过滤日志

### 导出日志
1. 在日志查看器中点击"导出日志"
2. 选择保存位置
3. 日志内容将保存为文本文件

### 清理日志
1. 在日志查看器中点击"清理旧日志"
2. 确认清理30天前的日志文件
3. 系统自动删除旧日志文件

### 直接查看日志文件
- 日志文件位置：`data/logs/app_YYYYMMDD.log`
- 使用文本编辑器打开查看
- 支持实时监控（如使用 `tail -f` 命令）

## 问题排查指南

### 1. 应用启动失败
查看日志中的启动序列：
```
[INFO] __main__: 启动 制度汇编管理系统 v1.3.1
[ERROR] database.migrations: 数据库初始化失败: ...
```

### 2. 文档导入失败
搜索相关文档名称或错误关键词：
```
[ERROR] core.document_service: 导入失败 xxx: 具体错误信息
```

### 3. 搜索功能异常
检查索引相关日志：
```
[WARNING] utils.search_engine: FTS5 索引写入失败: ...
[INFO] utils.search_engine: 重建搜索索引完成，索引文档数：xxx
```

### 4. 性能问题
查找耗时较长的操作：
```
[WARNING] 性能警告：批量导入 耗时 45.23秒 文件数量：100
```

## 技术实现

### 日志轮转机制
```python
from logging.handlers import RotatingFileHandler

file_handler = RotatingFileHandler(
    config.LOG_FILE,
    maxBytes=config.LOG_MAX_BYTES,  # 10MB
    backupCount=config.LOG_BACKUP_COUNT,  # 10个
    encoding='utf-8'
)
```

### 后台加载线程
```python
class LogLoadWorker(QThread):
    """后台加载日志的线程"""
    finished = pyqtSignal(list)
    error = pyqtSignal(str)
    
    def run(self):
        try:
            logs = LogManager.get_log_content(...)
            self.finished.emit(logs)
        except Exception as e:
            self.error.emit(str(e))
```

### 日志内容过滤
```python
def get_log_content(log_file, lines, level_filter, keyword):
    """读取日志内容"""
    filtered_lines = []
    for line in all_lines:
        # 级别过滤
        if level_filter and f"[{level_filter}]" not in line:
            continue
        # 关键词过滤
        if keyword and keyword.lower() not in line.lower():
            continue
        filtered_lines.append(line)
    return filtered_lines[-lines:]
```
